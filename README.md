# Netflix Movie Data Analysis 🎬

## Project Overview
This project performs **data analysis and visualization on Netflix movie data** using Python.  
The goal is to explore patterns in movie genres, distribution, and trends by analyzing a dataset containing around **9000 movies**.

The analysis is implemented in a Jupyter Notebook and uses popular Python libraries for data manipulation and visualization.

---

## Objectives
- Load and explore the Netflix movies dataset
- Clean and preprocess the data
- Convert relevant columns to appropriate data types
- Analyze the distribution of movie genres
- Identify the most frequent genres on Netflix
- Visualize insights using graphs and plots

---

## Dataset
The project uses the dataset:

**movies_9000_dataset.csv**

It contains information about movies available on Netflix, including attributes such as:
- Title
- Genre
- Release information
- Other descriptive fields used for analysis

---

## Technologies Used
- **Python**
- **Jupyter Notebook**
- **Pandas** – data manipulation and analysis
- **NumPy** – numerical operations
- **Matplotlib** – data visualization
- **Seaborn** – advanced statistical plots

---

## Project Workflow

1. **Import Libraries**
   - Import pandas, numpy, matplotlib, and seaborn.

2. **Load Dataset**
   - Read the dataset using `pandas.read_csv()`.

3. **Data Cleaning**
   - Handle missing values
   - Convert columns to appropriate types (e.g., category)

4. **Exploratory Data Analysis (EDA)**
   - Analyze genre distribution
   - Identify the most frequent movie genres
   - Understand dataset structure

5. **Data Visualization**
   - Create graphs and charts to represent insights visually

---

## Key Analysis Performed
- Genre frequency analysis
- Category conversion for efficient memory usage
- Visualization of movie distribution using plots

---

## How to Run the Project

1. Install required libraries:

```bash
pip install pandas numpy matplotlib seaborn
```

2. Open the notebook:

```bash
jupyter notebook
```

3. Run the file:

```
Movie data analysis netflix.ipynb
```
